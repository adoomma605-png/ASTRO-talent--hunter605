# Talent Hunter — Full-screen Feed Fix

نسخة معدلة من Talent Hunter تجعل كل منشور شريحة رأسية مستقلة بارتفاع الشاشة، مع انتقال منشور واحد لكل سحبة وإدارة تلقائية لتشغيل الفيديو وإيقاف الوسائط السابقة.

## أبرز التعديلات

- كل منشور يملأ شاشة الـFeed؛ السحب لأعلى ينتقل للمنشور التالي، ولأسفل للسابق.
- قفل الانتقال يمنع تخطي منشورات بسبب السحب السريع أو تكرار أحداث اللمس وعجلة الماوس.
- تشغيل فيديو المنشور النشط من البداية، وإيقاف وإرجاع وسائط المنشور السابق عند الانتقال.
- إزالة أزرار الأسهم وزر الصوت المنفصل.
- دعم البحث والتصنيفات، والتصفح بعجلة الماوس والأسهم على الكمبيوتر.
- واجهة موبايل بعرض وارتفاع الشاشة، وإطار Feed رأسي مركزي على الكمبيوتر.
- إصلاح اكتشاف MIME/امتداد الصور والفيديو والصوت، وإصلاح fallback التصنيف بين `type` و`category`.
- تحرير روابط معاينة الملفات المؤقتة، وإضافة السحب والإفلات لملف واحد، وانتظار جاهزية Supabase قبل الرفع.
- إضافة شعار SVG محلي.

## قاعدة البيانات

**لا توجد تغييرات على قاعدة البيانات.** لم يتم تعديل SQL أو الجداول أو الأعمدة أو سياسات RLS أو إعدادات Storage. تم الإبقاء على إعدادات اتصال Supabase الموجودة في `js/script.js` كما هي.

## تشغيل ونشر النسخة

1. فك ضغط الحزمة.
2. ارفع محتوياتها إلى نفس مستودع GitHub الذي ينشر الموقع، مع الحفاظ على بنية الملفات.
3. انتظر اكتمال GitHub Pages ثم حدّث الموقع تحديثًا قويًا (`Ctrl + F5` على الكمبيوتر).
4. لا تشغّل أي ملف SQL ولا تغيّر إعدادات Supabase.

## ملاحظة الصوت

يحاول الموقع تشغيل الفيديو بصوت بعد سحبة المستخدم. بعض المتصفحات تمنع التشغيل التلقائي المسموع؛ عندها يبدأ الفيديو صامتًا ويمكن تفعيل الصوت بالنقر على الفيديو. هذه سياسة من المتصفح وليست إعدادًا في قاعدة البيانات.

## الاختبارات

نجحت اختبارات الواجهة المحلية على Chromium بمقاسي 390×844 و1440×900، بما في ذلك انتقال منشور واحد، ارتفاع الشاشة، وإيقاف الوسائط السابقة. لم يتم تنفيذ اتصال أو رفع فعلي إلى Supabase خلال الاختبارات. راجع `REPORT_AR.md` للتقرير التفصيلي وحدود الاختبار.
